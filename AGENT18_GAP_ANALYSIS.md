## 2. Preservation Directives
- **Zero Regression**: All 15 existing tests (10 Core + 5 RAG) MUST continue to pass 100%.
- **Color Palette & Design Language**: `public/style.css` tokens (`--primary-color`, `--bg-color`, `--card-bg`, etc.) must remain unchanged.
- **Deterministic Supremacy**: RAG and LLM inference output remain capped at Level 7 (`LLM_INFERENCE`) and CANNOT independently verify indexing or quartile status.
- **Zero Fabrication**: Any unconfigured API credential or missing dataset returns `SOURCE_STATUS = UNAVAILABLE` and is cleanly reported without generating fake numbers.
